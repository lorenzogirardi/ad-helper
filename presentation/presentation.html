AD Helper

Read-only web UI for Active Directory

Context Method Application Review

The problem

User and constraints

  • Existing corporate Active Directory
  • Mac without a handy LDAP client
  • Manual workflow with ldapsearch from the terminal

Functional requirements

  • Search users by name, sAMAccountName, email
  • See OU path, memberOf, active/disabled status
  • Search groups and members (groups with more than 1500 members)
  • Export CSV/JSON
  • Read-only, Docker, no user login

Tech stack

Backend

Node.js 20 + Express 4 + ldapjs 3

Frontend

Vanilla HTML/JS, zero dependencies

Deploy

Docker Compose, node:20-alpine

Auth

LDAP bind with a normal account

Language
JavaScript (ES2020)
Ports
host 127.0.0.1:3080 → container 3000
Persistence
Stateless, no cache
AD limit
Ranged retrieval for attributes with >1500 values

Independent review: findings

Wrong LDAP timeout

Docs said infinite default → fixed: timeout: 15000ms, connectTimeout: 10000ms

Port 3080 wording

"PORT override" → fixed: Compose maps host 127.0.0.1:3080 to container 3000

Personal and specific data

Removed names, domains, real groups, example passwords → generic placeholders

Diátaxis label

First setup → ## Tutorial: first start

Roadmap in Reference

"Future" section → moved to open-questions.md

Independent review: second round

Ranged retrieval chunk

Docs said range of 1500 → fixed: pageSize = 1000, member;range=0-999, 1000-1999, …

Stale line counts

Modules table realigned to the real wc -l of the sources

Unqualified requirement

LDAPS in production → decision to confirm (Q-TLS), not an implemented requirement

Result limit

"default ~1500" → depends on the server, not imposed by the code

Lesson: every numeric claim must be checked against the source, not against memory of AD behaviour.

What we learned

  • Diátaxis drives the structure, avoids the "monolithic wiki"
  • Meta-layers make the docs maintainable and verifiable
  • Ownership by role, not by name: no blame, no rot
  • Independent review is mandatory: one writes, another verifies
  • Privacy by default: no names, no internal domains, no example passwords
