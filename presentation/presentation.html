AD Helper

Web UI read-only per Active Directory

Contestualizzazione Metodo Applicazione Review

Il problema

Utente e vincoli

  • Active Directory aziendale esistente
  • Mac senza client LDAP comodo
  • Workflow manuale via ldapsearch da terminale

Requisiti funzionali

  • Cercare utenti per nome, sAMAccountName, email
  • Vedere OU path, memberOf, stato attivo/disabilitato
  • Cercare gruppi e membri (gruppi oltre i 1500 membri)
  • Export CSV/JSON
  • Solo lettura, Docker, niente login utente

Stack tecnico

Backend

Node.js 20 + Express 4 + ldapjs 3

Frontend

Vanilla HTML/JS, zero dipendenze

Deploy

Docker Compose, node:20-alpine

Auth

Bind LDAP con service account

Linguaggio
JavaScript (ES2020)
Porte
host 127.0.0.1:3080 → container 3000
Persistenza
Stateless, nessuna cache
Limite AD
Ranged retrieval per attributi >1500 valori

Cosa abbiamo imparato

  • Diátaxis guida la struttura, evita il "monolite wiki"
  • Meta-layers rendono la doc manutenibile e verificabile
  • Ownership per ruolo non per nome — no blame, no rot
  • Review indipendente è obbligatoria: io scrivo, un altro verifica
  • Privacy by default: niente nomi, niente domini interni, niente password di esempio

Prossimi passi

  • Terza review indipendente dopo seconda tornata di fix
  • Se APPROVED: review-status.json → validated
  • Considerare LDAPS + cert validation per produzione
  • Valutare cache (Q-CACHE) se ricerche frequenti
  • Testare rangedSearch su gruppo reale con >1500 membri
